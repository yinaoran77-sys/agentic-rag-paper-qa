## 📌 项目一句话

针对传统 RAG **答非所问、检索准确率低、响应慢** 三大痛点，打造具备**自主推理能力**的智能论文问答系统。支持学术论文定时爬取与私有文档上传，提供**标准与 Agentic 双模式问答**，实现**全链路可观测**与**一键部署**。

## 🏗️ 技术栈（8 大组件）

| 层级 | 技术 | 职责 |
|------|------|------|
| **API 框架** | FastAPI | 高性能异步后端服务 |
| **关系数据库** | PostgreSQL | 用户、文档、会话、问答记录元数据 |
| **搜索引擎** | OpenSearch | 混合检索引擎（BM25 全文 + KNN 向量） |
| **缓存层** | Redis | 缓存答案、会话状态、语义缓存 |
| **AI 编排** | LangGraph | Agent 工作流：问题链校验 → 查询改写 → 检索 → 打分 → 补充检索 |
| **LLM 推理** | Ollama | 本地大模型部署（无需联网） |
| **文档流水线** | Airflow + Docling | 定时爬取 arXiv + 文档解析入库 |
| **可观测性** | Langfuse | 请求级 + 节点级追踪 |
| **部署** | Docker Compose | 一键编排全栈服务 |

## 🎯 核心功能模块

### 模块 1：后端架构（FastAPI + PostgreSQL + OpenSearch + Redis + Ollama）

- ✅ 混合检索（BM25 + 向量）
- ✅ 流式问答（SSE Streaming）
- ✅ 文档上传与全文浏览
- ✅ 异步处理队列

### 模块 2：混合检索引擎

- **BM25 + 向量 RRF 融合检索**
  - 异构自动降维 BM25（不同字段权重自动调整）
  - RRF（Reciprocal Rank Fusion）融合排序
- **Airflow + Docling 摄取 arXiv**
  - 定时爬取最新论文
  - 自动解析 PDF/Word/TXT
- **BGE 向量化嵌入**
  - 文档分块 → BGE 编码 → OpenSearch KNN 索引
- **自动建索引**
  - 上传文档后异步分块、编码、入库

### 模块 3：LangGraph Agent 推理链

- **问题链校验** — 判断问题是否需要澄清/分解
- **查询改写** — 将用户问题改写成更适合检索的查询
- **片段打分** — 对检索结果的相关性打分
- **补充检索** — 低分时自动扩展查询二次检索
- **幻觉控制**
  - 离线评测指标：**幻览式召回率从 17.4% 降至 0%**
  - 脱靶率检索文档的幻觉式召回 = 0

### 模块 4：缓存与性能

- **Redis 缓存存疑答案**
  - 语义缓存：相似问题命中缓存
  - 重复相同问题响应约 **4ms**
- **Langfuse 全链路追踪**
  - 请求级追踪：每次问答的完整链路
  - 节点级追踪：LangGraph 每个节点的输入输出、耗时

### 模块 5：部署

- **Docker Compose 一键编排**
  - 全栈服务一键启动
  - 开发/测试/生产环境统一

## 📝 关键术语解释

| 术语 | 解释 |
|------|------|
| **BM25** | 经典全文检索算法，基于词频-逆文档频率 |
| **RRF (Reciprocal Rank Fusion)** | 融合排序算法，将多个排序列表合并成一个 |
| **BGE** | BAAI General Embedding，中文语义嵌入模型 |
| **KNN** | K-Nearest Neighbors，向量相似度检索 |
| **SSE** | Server-Sent Events，服务器向客户端推送流式数据 |
| **幻觉式召回** | 检索到了不相关的文档，导致 LLM 产生幻觉 |
| **脱靶率** | 检索结果与问题不相关的比例 |
| **Langfuse** | LLM 应用的可观测平台，追踪每次请求 |
| **Docling** | IBM 开源文档解析工具，支持 PDF/Word 等 |
